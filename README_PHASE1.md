# MatchMind — المرحلة الأولى (واجهة + تنقل + بيانات تجريبية)

## ما تم إنجازه في هذه المرحلة
- مشروع Flutter كامل بهوية MatchMind (الثيم الداكن الكحلي + الأخضر).
- دعم عربي RTL كامل عبر `flutter_localizations` و`Directionality`.
- تبويبات سفلية خمسة: الرئيسية، المباريات، التحليل، المجتمع، حسابي.
- شاشة رئيسية فيها: شعار، بحث، مباريات مباشرة، مباريات اليوم، تقارير (فارغة حاليًا).
- شاشة مباريات بأربعة تبويبات فرعية: مباشر / اليوم / القادمة / النتائج.
- بطاقة مباراة موحّدة قابلة لإعادة الاستخدام (`MatchCard`).
- بيانات **تجريبية فقط** في `lib/data/mock_data.dart`، موسومة بوضوح
  (`isMockData: true` + شارة "بيانات تجريبية" ظاهرة على كل بطاقة).
- اختبار وحدة (`test/app_smoke_test.dart`) يتحقق من إقلاع التطبيق والتنقل.

## ما لم يُنفَّذ بعد (مؤجل للمراحل القادمة)
- لا يوجد اتصال حقيقي بـ Supabase أو أي API — هذا المرحلة الثانية والثالثة.
- محلل الذكاء الاصطناعي: شاشة توضيحية فقط حتى الآن (المرحلة الرابعة).
- تسجيل الدخول، التوقعات، المجتمع الفعلي: لاحقًا.

## خطوات التشغيل على جهازك (Windows + VS Code)

### 1) تأكد أن Flutter مثبت
افتح PowerShell داخل VS Code (``Ctrl + ` ``) واكتب:

```powershell
flutter doctor -v
```

إذا ظهرت لك علامات ❌، أرسل لي النتيجة كاملة وسأشرح كيف تحلها قبل أي خطوة ثانية.
إذا لم يكن Flutter مثبتًا أصلًا، أخبرني وسأعطيك خطوات التثبيت على Windows.

### 2) تأكد من وجود جهاز لتشغيل التطبيق
```powershell
flutter devices
```
يمكنك استخدام محاكي Android (Android Emulator) أو هاتف حقيقي موصول بوضع USB Debugging.

### 3) افتح مجلد المشروع
افتح VS Code على المجلد: `matchmind/mobile` (هذا هو المجلد الذي يحتوي على `pubspec.yaml`).

### 4) نزّل الحزم المطلوبة
```powershell
flutter pub get
```

### 5) تحقق من الكود والاختبارات
```powershell
flutter analyze
flutter test
```
إذا ظهر أي خطأ، انسخ لي رسالة الخطأ كاملة ولا تخمّن الحل بنفسك.

### 6) شغّل التطبيق
```powershell
flutter run
```
(اختر جهازك من القائمة إذا طُلب منك ذلك)

## بعد التأكد أن كل شيء يعمل
أخبرني بنتيجة `flutter analyze` و `flutter test` و `flutter run`،
وبعدها ننتقل للمرحلة الثانية: إعداد Supabase (قاعدة البيانات + تسجيل الدخول + RLS).

**لا تنتقل لأي خطوة لاحقة قبل أن تخبرني أن هذه المرحلة اشتغلت عندك بدون أخطاء.**
